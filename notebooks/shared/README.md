# Notebooks compartilhados

Use esta pasta para exploração reproduzível que beneficie toda a equipe, como análise de uma amostra sintética, comparação de estratégias ou validação de uma ferramenta.

Regras:

- não inclua credenciais nem dados restritos;
- limpe saídas volumosas antes da revisão;
- registre origem e licença de qualquer amostra;
- mova lógica reutilizável e testada para src/iica_csv;
- notebooks não substituem o fluxo principal da aplicação.
