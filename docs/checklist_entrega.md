# Checklist de entrega

Prazo oficial: **16/08/2026 às 23h59**.

## Funcionamento

- [ ] A aplicação instala e executa seguindo o README.
- [ ] O upload aceita ZIP contendo um ou mais CSVs e dicionário de dados.
- [ ] Os arquivos são processados automaticamente.
- [ ] A interface de consulta aparece após o processamento.
- [ ] O agente interpreta perguntas em linguagem natural.
- [ ] As respostas usam apenas os dados carregados.
- [ ] Texto, tabelas e gráficos são usados quando apropriado.
- [ ] Entradas inválidas e falhas externas são tratadas.

## Qualidade

- [ ] Interface, processamento, agente e ferramentas estão separados.
- [ ] Testes automatizados passam.
- [ ] python scripts/validate_structure.py passa.
- [ ] Nenhuma credencial ou dado sensível está versionado.
- [ ] A equipe consegue explicar a arquitetura e as decisões.

## Evidências e relatório

- [ ] Quatro perguntas representativas foram registradas.
- [ ] Cada pergunta possui resposta e validação contra os dados.
- [ ] O relatório identifica o framework escolhido.
- [ ] O relatório descreve arquitetura, agentes e fluxo.
- [ ] Limitações e erros conhecidos estão documentados.

## Pacote final

- [ ] Relatório técnico exportado em PDF.
- [ ] ZIP contém todo o código-fonte necessário.
- [ ] ZIP não contém .env, credenciais, ambiente virtual ou dados proibidos.
- [ ] Instalação foi testada a partir de uma cópia limpa.
